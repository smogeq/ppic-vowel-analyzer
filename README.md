# Vowel Frequency Analyzer

UTS 43030 Professional Practice in Computing, Software Development module, Lecture 3 activities.

A custom GitHub Action built with Docker. On every push to `main`, the workflow builds a Docker image, runs `frequency.py` on `data.txt`, and appends the result, the contributor's username and a timestamp to this README.
